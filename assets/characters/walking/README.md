# Walking sprites

11 character sheets generated with the built-in ChatGPT image generator from the original character references.
Each PNG has a transparent background and measures 288 × 384 pixels.
Cells are 72 × 96 pixels. Rows: down, up, right, left. Columns: idle, left contact, passing, right contact.

`walk.js` plays contact / passing / opposite contact / passing according to actual distance moved.
Standing characters use column 0. Existing images remain available as fallbacks.
The epilogue parents and the disguised candidates in the mother-finding game use these sheets too.

Open `walk-preview.html` at the project root to review all directions and movement speed.
